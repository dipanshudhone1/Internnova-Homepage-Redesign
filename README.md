# InternNova Official Homepage Redesign 🚀

A modern, responsive, and user-friendly homepage redesign for **InternNova**, created as part of a web development internship project.

## 🌐 Project Overview

This project focuses on redesigning the InternNova homepage with a clean, professional, and modern interface while maintaining the brand's identity.

The website is designed to provide students with an engaging experience while exploring internship programs, domains, mentorship, workshops, testimonials, and other opportunities.

## ✨ Features

* Responsive design for Desktop, Tablet, and Mobile
* Modern navigation bar with mobile menu
* Attractive hero section
* About InternNova section
* Internship Programs
* Internship Domains
* Why Choose InternNova
* Learning & Mentorship section
* Workshops section
* Student/Intern Testimonials
* Statistics & Achievements
* Frequently Asked Questions (FAQ)
* Call-to-Action section
* Professional footer
* Smooth animations and interactions
* Clean and organized UI

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
